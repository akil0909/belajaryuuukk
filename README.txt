STUDIA — GitHub Pages ready static version

Upload index.html, styles.css, app.js, and .nojekyll to the ROOT of a public GitHub repository named akil0909.github.io.
Then open Settings -> Pages, choose Deploy from a branch, choose Branch: main and Folder: /(root), and Save.

Important:
- This is a static version with no Node.js backend or hosted AI API. On GitHub Pages, Studia uses its local summary fallback.
- The materials/progress are stored in the visitor's own browser (IndexedDB/localStorage), not shared or backed up to a central server.
- PDF/DOCX/PPTX text extraction uses libraries loaded from CDNs, so internet access is needed.
- Photos are previewed but OCR is not included. URL contents are not fetched automatically.
- Do not upload private study files or API keys to this repository.
